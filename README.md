# Predicting Airline Satisfaction

Kaggle code and notebooks for the Playground Series S6E10 airline-satisfaction competition.

The project contains experiments E1–E9, progressing from pretrained tabular models and boosted-tree ensembles to neural networks, fold-safe teacher/route features, and a nested RealMLP–TabM–LightGBM ensemble.

See [`airline_satisfaction/README.md`](airline_satisfaction/README.md) for the experiment index and Kaggle running instructions.

Training/test datasets, pretrained weights, caches, and generated submission files are intentionally excluded from this repository.
